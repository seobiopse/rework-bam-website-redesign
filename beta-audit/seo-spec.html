Badge-A-Minit: SEO Metadata & Structured Data Spec

Written for the beta rebuild of https://badge-a-minit.com.au. Covers the homepage, the 18 category pages and the 109 product pages. Structured data is generated by the site templates, so section 2 lists the exact strings and fields to replace. Section 3 onward gives the unique title, description and social tags for each page.

How the copy was written - Australian English. One primary keyword phrase per page, put first in the title. Every title is 60 characters or fewer and every meta description is 155 or fewer. - Product and category facts (sizes, materials, minimums, finishes) come from the approved writer content. "From 25 units", "no minimum order" and "2-day dispatch" appear only where the writer file says so. - No prices, ratings or stock claims were invented. Items marked [Confirm] have no writer content and need a check. - Every title and description is unique across the site (checked).

Assumptions to confirm - Canonical and og:url use the production domain https://badge-a-minit.com.au (beta currently points to the beta domain). - The default social image is the existing BADGE.jpg.png (1200x630). Replace it with a product or category photo per page as images are populated. - og:title / twitter:title are the title tag without the | Badge-A-Minit suffix (the brand is carried by og:site_name).

2. Structured data (dynamic): strings and fields to replace

Current problem: on all 109 product pages and all 18 category pages, two <script type="application/ld+json"> blocks print the template source instead of JSON, for example:

!!json_encode($breadcrumbSchema, JSON_UNESCAPED_SLASHES | JSON_PRETTY_PRINT) !!
!!json_encode($productSchema, JSON_UNESCAPED_SLASHES | JSON_PRETTY_PRINT) !!
!!json_encode($schema, JSON_UNESCAPED_SLASHES | JSON_PRETTY_PRINT) !!

These strings must be replaced by the rendered JSON. The existing FAQPage blocks (valid) can stay as they are.

Homepage - Keep the existing valid LocalBusiness block (@id https://badge-a-minit.com.au/#organization, address 56a Prospect Road, Prospect SA 5082, phone +61-8-83631655, geo, areaServed). - Add a WebSite block: name = Badge-A-Minit, url = https://badge-a-minit.com.au/, publisher = {"@id": "https://badge-a-minit.com.au/#organization"}. - Add an FAQPage block built from the 13 questions and answers already visible in the FAQ section (Question.name = question text, acceptedAnswer.text = answer text).

Category pages (replace $breadcrumbSchema and $schema)

BreadcrumbList
  item 1: name "Home"                    item "https://badge-a-minit.com.au/"
  item 2: name {{parent_category_name}}  item {{parent_category_url}}      (only on the 4 name-badge sub-categories and the Multi Press machine page)
  item last: name {{category_name}}      item {{canonical}}

CollectionPage
  name        = {{category_name}}
  url         = {{canonical}}
  description = {{meta_description}}
  isPartOf    = WebSite "Badge-A-Minit" ("https://badge-a-minit.com.au/")
  mainEntity  = ItemList
      itemListElement[i]: position {{i}}, name {{product_name}}, url {{product_canonical_url}}

Product pages (replace $breadcrumbSchema and $productSchema)

BreadcrumbList
  item 1: "Home"                              "https://badge-a-minit.com.au/"
  item 2: {{category_name}}                   {{category_url}}
  item 3: {{product_name}}                    {{canonical}}

Product
  name        = {{product_name}}
  description = {{meta_description}}   (or the first paragraph of the product overview)
  url         = {{canonical}}
  image       = [{{product_image_url}}, ...]   (must be a real product image; the default BADGE.jpg.png is only a fallback)
  category    = {{category_name}}
  brand       = Organization "Badge-A-Minit"
  manufacturer= Organization "Badge-A-Minit"
  sku / mpn   = {{sku}}                (include only if the product has one)
  offers      = Offer / AggregateOffer
      priceCurrency = "AUD"
      price or lowPrice = {{lowest_variant_price}}     (number only, e.g. 0.36; omit the whole offers block if the product has no price)
      availability = "https://schema.org/InStock" or "https://schema.org/OutOfStock"   ({{stock_status}})
      url = {{canonical}}
  aggregateRating / review = only when real product reviews are on the page (do not reuse the business's Google rating here)

Rule for all templates: values must come from the same fields that render on the page, and empty fields should be omitted instead of printed as empty strings.
